# Employee Management System

## Project Overview

The Employee Management System is a menu-driven Python application designed to manage basic employee information. It allows users to add new employee records, view all stored employee details, and search for a specific employee using their Employee ID.

This project demonstrates the practical application of Python fundamentals, including dictionaries, functions, loops, conditional statements, and user input handling.

## Features

- **Add Employee:** Add an employee's ID, name, age, department, and salary.
- **View All Employees:** Display the details of all employees stored in the system.
- **Search Employee:** Find an employee using their unique Employee ID.
- **Duplicate ID Check:** Prevent adding an employee with an ID that already exists.
- **Interactive Menu:** Navigate through the available operations using a menu-driven interface.
- **Exit Option:** Exit the application when finished.

## Technologies Used

- Python 3
- Dictionaries
- Functions
- Conditional Statements
- Loops (`while` and `for`)
- User Input and Output

## Employee Information Stored

Each employee record contains:

| Field | Description |
|---|---|
| Employee ID | Unique identifier for an employee |
| Name | Employee's full name |
| Age | Employee's age |
| Department | Employee's department |
| Salary | Employee's salary |

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in your code editor or terminal.
3. Make sure Python 3 is installed.
4. Run the Python file using:

   ```bash
   python "Employee Management System.py"
   ```

5. Follow the on-screen menu to perform the required operations.

## Menu Options

1. Add Employee
2. View All Employees
3. Search for Employee
4. Exit
